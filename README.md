# OpenTierList
_Comprehensive open-source tool for custom tier list creation._


**🚀Features:**
- custom tiers (name & color)
- sort images & text
- export as PNG or JSON
- can be run as a local program or website

**🔐Privacy:**
- uses the qobuz-connect api
- the service itself does not touch or look at you data
